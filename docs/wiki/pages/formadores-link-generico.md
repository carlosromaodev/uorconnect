# Formadores - Link Genérico

Status: rascunho
Última atualização: 2026-05-17
Fontes principais: `raw/obsidian-cofre/Formadores - Link generico.md`

## Objetivo

Criar um fluxo estável para formadores se cadastrarem por link genérico, sem depender de cadastro manual direto na admin.

## Fluxo Desejado

1. Admin gera ou partilha link genérico de cadastro.
2. Formador abre o link.
3. Sistema mostra uma tela profissional de boas-vindas.
4. Formador faz autenticação.
5. Formador completa perfil.
6. Formador escolhe o curso que vai ministrar.
7. Admin valida ou aprova o vínculo.
8. Formador ganha acesso limitado.

## Acesso do Formador

O formador deve ver apenas:

- curso ou cursos associados;
- quantidade de estudantes inscritos;
- lista básica de estudantes quando operacionalmente necessário;
- materiais ou comunicados do curso.

Não deve ver:

- finanças gerais;
- todos os projetos;
- dados sensíveis de outros cursos;
- configurações globais;
- votos globais;
- relatórios administrativos completos.

## Campos Principais

- Nome completo.
- Telefone.
- Email, se tiver.
- Área de formação.
- LinkedIn opcional.
- Bio profissional curta.
- Experiência relevante.
- Curso que vai ministrar.

## Decisões Pendentes

- Se formador fica ativo imediatamente ou precisa aprovação manual.
- Se pode estar ligado a mais de um curso.
- Se o link genérico é permanente ou expira.
- Se links podem vir com curso pré-selecionado.
